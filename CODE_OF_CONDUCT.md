# Code of Conduct

This is a small open-source project maintained by one person in spare time.

## The short version

Be decent. Don't be a jerk.

If you open an issue, include enough information to reproduce the problem. If
you submit a PR, explain what it does and why. If you disagree with a decision,
say so — respectfully.

Harassment, personal attacks, and bad-faith behaviour will get you blocked.
There's no appeals process. Life's too short.

## Reporting

If something goes wrong, open an issue or email ramsy0dev@gmail.com. I'll handle
it as quickly as I can.
